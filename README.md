# 🥘 Tachinho — Comprar ou fazer?

Aplicação independente para comparar o custo de comprar produtos com o custo estimado de os fazer em casa e calcular a poupança potencial.

## Estado

Em desenvolvimento e validação. Ainda não publicado para utilização final.

## Princípios

- O preço real introduzido pela pessoa prevalece sobre preços de referência.
- Só são usadas automaticamente referências de preço confirmadas, compatíveis e dentro do período de revisão.
- Produtos sem custo caseiro e rendimento validados não entram nos cálculos.
- As simulações não são guardadas de forma permanente.
- Os dados e cálculos do Tachinho estão separados do HA Smart Pro.
